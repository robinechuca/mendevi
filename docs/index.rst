Dataset
=======

The source videos come from three different sources:

#. 30 short lossless 4k `JVET CTC videos <https://dash-large-files.akamaized.net/WAVE/3GPP/5GVideo/ReferenceSequences/>`_, `download ctc.torrent link <https://gitlab.inria.fr/rrichard/mendevi/-/raw/main/dataset/video/ctc.torrent?inline=false>`_ (140 Go).
#. 1 tall lossless 4k `Big Buck Bunny <https://media.xiph.org/BBB/>`_, `download bbb.mp4.torrent link <https://gitlab.inria.fr/rrichard/mendevi/-/raw/main/dataset/video/bbb.mp4.torrent?inline=false>`_ (101 Go).
#. 1000 short lossly 4k `Inter4K <https://alexandrosstergiou.github.io/datasets/Inter4K/index.html>`_, `download inter4k.torrent link <https://gitlab.inria.fr/rrichard/mendevi/-/raw/main/dataset/video/inter4k.torrent?inline=false>`_ (16 Go).
