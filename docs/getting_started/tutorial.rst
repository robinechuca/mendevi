Tutorial
========

There is a lot of jupyter-notebook examples.
To run them yourself, you must to install mendevi with the flag *all*, like that: ``uv pip install mendevi[all]``.

Then you can execute jupyter with the following cmd:

.. code:: shell

    jupyter-notebook examples/
